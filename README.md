
# 🌸 PaperNest — Kawaii Stationery Store

PaperNest is a cute, pastel-themed stationery e-commerce website developed as part of the MIS455 Midterm Practical Examination.

The website allows visitors to explore stationery products, calculate shopping costs, manage a shopping cart, and interact with a contact form.

## 🌐 Live Website

https://kawaipapernest.netlify.app/

## ✨ Features

### 🏠 Home Page
- Attractive kawaii-themed design
- Featured stationery products
- Responsive layout using CSS Flexbox
- Multi-product shopping calculator
- Automatic discount calculation
- Total and payable amount display

### 🛍️ Products Page
- Six stationery product cards
- Responsive CSS Grid layout
- Product images, descriptions, and prices
- Add to Cart functionality
- Shopping cart summary
- Automatic discount calculation
- Clear Cart functionality
- Kawaii popup notifications

### 💌 Contact Us Page
- Contact information
- Stationery images
- Interactive contact form
- JavaScript input validation
- Clear Form functionality

## 🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling, Flexbox, Grid, and responsiveness
- JavaScript — Interactive features and validation
- Git & GitHub — Version control
- Netlify — Website deployment

## 💰 Discount Policy

Customers receive a Tk 100 discount when their total purchase amount is Tk 1000 or more.

For example:

- Total Price: Tk 1250
- Discount: Tk 100
- Final Payable Amount: Tk 1150

## 🚀 How to Run Locally

1. Clone the repository:

   git clone https://github.com/shaikaislamarpita/2311080_MIS455_MID_Project.git

2. Open the project folder in VS Code.
3. Open `index.html` with Live Server or a web browser.
4. Navigate between Home, Products, and Contact Us.

No backend or database setup is required.

## 📝 Project Limitations

This is a frontend demonstration website.

- The shopping cart resets when the page is refreshed.
- The contact form validates input but does not send emails.
- No real payment processing or order management is implemented.
